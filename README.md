# Atelier Digital

Create a **high-end, visually immersive portfolio website for a fashion designer**.

Use the attached reference image ONLY as a reference for the overall content hierarchy and portfolio structure. **Do NOT copy its colors, typography, layout, illustrations, or exact design.**

The new website should feel significantly more **fashion-forward, editorial, artistic, luxurious and memorable**.

Think:

**Vogue editorial × luxury fashion house × contemporary art gallery × modern designer portfolio**

The website should immediately feel like a fashion designer's creative world rather than a generic portfolio website.

---

# 1. NEW VISUAL DIRECTION

Do NOT use the beige + muted olive color palette from the reference.

Instead use a sophisticated editorial palette:

### Main colors

* Deep black: #111111

* Warm ivory: #F5F1EA

* Off-white: #FAF9F6

### Accent

Use **deep burgundy / wine red** sparingly.

Optional secondary accent:

* Metallic champagne / muted gold

The website should primarily be black, ivory and white, with burgundy appearing only in important interactive elements.

Avoid:

* Pastel green

* Olive backgrounds

* Generic beige cards

* Excessive gold

* Bright gradients

* Corporate blue

* Overly colorful UI

The fashion photography should provide most of the visual color.

---

# 2. TYPOGRAPHY

Use a high-fashion editorial typography combination.

### Display typography

Use an elegant high-contrast serif similar to:

* Bodoni

* Didot

* Cormorant Garamond

### Supporting typography

Use:

* Helvetica Neue

* Inter

* Manrope

Use **large serif typography** for collection names and major statements.

Use clean sans-serif typography for navigation, descriptions and metadata.

Typography should feel like a luxury fashion magazine.

---

# 3. NAVIGATION

Create a minimal navigation.

Left:

**[DESIGNER NAME]**

Center/right:

WORK

COLLECTIONS

ABOUT

PROCESS

CONTACT

Add a small circular menu button on mobile.

Keep navigation extremely minimal.

On scroll:

* Navigation becomes slightly opaque

* Background gets a subtle blur

* Logo remains visible

* Navigation smoothly shrinks

---

# 4. HERO — MAKE THIS THE MOST IMPRESSIVE SECTION

Do NOT create a normal portfolio hero.

Create an **editorial full-screen hero**.

Use a large fashion photograph as the main visual.

Use a temporary high-quality fashion image from a source such as Unsplash.

Suitable image directions include:

* Fashion designer in studio

* Designer working with fabric

* Editorial fashion portrait

* Model wearing an experimental garment

* Designer sketching

* Fashion runway

For example, use suitable Unsplash imagery such as fashion studio/editorial photography.

### Hero layout

Full viewport.

Large image occupying approximately 65–75% of the screen.

Place typography partially overlapping the image.

Example:

**[DESIGNER NAME]**

Fashion Designer

Creative Director

Then a small statement:

**"I create clothing that exists somewhere between identity, culture and artistic expression."**

CTA:

**EXPLORE COLLECTIONS →**

Add small vertical text along the side:

**FASHION / FORM / CULTURE / 2026**

---

# 5. HERO ANIMATION

Make the entrance cinematic.

On page load:

1. Black screen for approximately 500ms

2. Designer name slowly appears

3. Hero image reveals using a vertical mask

4. Subtitle fades upward

5. Navigation fades in

6. Small decorative line expands horizontally

Do NOT use fast or flashy animations.

Everything should feel slow, elegant and intentional.

---

# 6. INTRODUCTION

After the hero, create a large editorial statement.

Use oversized typography:

**"I DON'T DESIGN CLOTHES.

I DESIGN A LANGUAGE OF FORM."**

Then a short paragraph introducing the designer.

Keep the section spacious.

Use a small portrait or studio image overlapping the typography.

Add a subtle scroll animation where the text moves slightly slower than the image.

---

# 7. FEATURED COLLECTIONS

Heading:

**SELECTED COLLECTIONS**

Small caption:

**A study of form, material, movement and identity.**

Create an unconventional editorial grid.

Do NOT create standard equal-sized cards.

Instead:

* Collection 01 → huge vertical image

* Collection 02 → wide landscape image

* Collection 03 → cropped editorial image

* Collection 04 → full-width runway image

Allow images to overlap slightly.

Each project should contain:

**01 / COLLECTION NAME**

Spring Summer 2026

Concept / Womenswear / Couture

On hover:

* Image zooms very slowly

* Dark overlay appears

* Collection title slides upward

* "VIEW COLLECTION →" appears

* Cursor transforms into a circular "VIEW" indicator

---

# 8. IMAGE SOURCING

Use high-quality temporary images from **Unsplash or Pexels**.

Do not use random generic stock images.

Search for imagery around:

* fashion designer studio

* fashion editorial

* haute couture

* runway fashion

* textile design

* fashion sketches

* fabric texture

* fashion backstage

* designer workspace

* model editorial

* garment construction

Use a mixture of:

1. Designer portraits

2. Runway photographs

3. Editorial model photographs

4. Fabric close-ups

5. Sketches

6. Studio photographs

7. Behind-the-scenes images

Prioritize cinematic/editorial imagery.

---

# 9. COLLECTION DETAIL EXPERIENCE

When the user clicks a collection, open a dedicated immersive project page.

At the top:

**COLLECTION 01**

# ECHOES

**AUTUMN / WINTER 2026**

Then a large full-screen image.

Add a short concept:

"Echoes explores memory, movement and identity through sculptural silhouettes, layered textiles and unexpected proportions."

Then create a flowing editorial gallery.

Do NOT use a standard image carousel.

Instead use:

* Full-screen images

* Vertical images

* Cropped close-ups

* Overlapping photographs

* Small detail shots

* Full-width runway images

Make the page feel like scrolling through a luxury fashion editorial.

---

# 10. PARALLAX IMAGE EFFECTS

Add subtle parallax effects.

For example:

Background image moves at 0.85x scroll speed.

Foreground typography moves at 1x.

Small decorative images move at 1.1x.

This creates depth without becoming distracting.

---

# 11. DESIGN PROCESS

Create an editorial section:

# FROM IDEA TO FORM

Show the creative process:

01 — RESEARCH

Culture, architecture, art and visual references.

02 — CONCEPT

Moodboards, silhouettes, colors and materials.

03 — EXPERIMENT

Fabric manipulation, draping and pattern exploration.

04 — DEVELOPMENT

Fittings, construction and refinement.

05 — FINAL FORM

Finished garments and editorial presentation.

Use images of sketches, fabrics and studio work.

Use horizontal scrolling or a pinned vertical scroll interaction.

---

# 12. SKETCHBOOK SECTION

Create a visually experimental section called:

**THE SKETCHBOOK**

Instead of a normal grid, create a floating collage of:

* Fashion sketches

* Fabric samples

* Handwritten notes

* Moodboards

* Color swatches

* Garment details

* Reference photographs

Images should slightly overlap.

On hover, individual images should lift slightly from the page.

Add subtle rotation effects.

Keep it sophisticated rather than messy.

---

# 13. ABOUT THE DESIGNER

Create a dramatic split-screen section.

Left:

Large black-and-white portrait of the designer.

Right:

**ABOUT THE DESIGNER**

Short biography.

Then show:

Based in — [CITY]

Specialization — [SPECIALIZATION]

Experience — [X YEARS]

Focus — Couture / Womenswear / Menswear / Sustainable Fashion

Add a handwritten-style signature beneath the biography.

---

# 14. DESIGN PHILOSOPHY

Create a full-width black section.

Use oversized ivory serif typography:

**"FASHION IS MEMORY,

MOVEMENT AND IDENTITY."**

Then reveal three keywords one at a time:

**FORM**

**TEXTURE**

**IDENTITY**

Each word should animate into view as the user scrolls.

---

# 15. RUNWAY / EDITORIAL SECTION

Create a cinematic section titled:

**IN MOTION**

Use a large runway photograph or fashion editorial image.

If video is available, allow a muted looping fashion video.

If video is unavailable, create a slow Ken Burns effect on a still image.

Use a small label:

**RUNWAY / 2026**

Add a play button if video is available.

---

# 16. PRESS & COLLABORATIONS

Minimal editorial section.

Heading:

**SELECTED PRESS & COLLABORATIONS**

Display publication / collaboration names in large typography.

Example:

VOGUE

ELLE

FASHION WEEK

DESIGN WEEK

[BRAND]

[STUDIO]

Do not create fake publication logos.

Use text placeholders until real collaborations are provided.

---

# 17. TESTIMONIALS

Avoid generic testimonial cards.

Instead create one large quote:

**"The collection feels less like clothing and more like a visual language."**

Then:

— [CLIENT / CREATIVE DIRECTOR]

Use a black or burgundy background.

Animate the quote with a slow text reveal.

The CTA should have a subtle hover animation.

# 20. CURSOR INTERACTION

Create a custom cursor.

Normal state:

Small circle.

When hovering over an image:

Circle expands.

Text appears:

**VIEW**

When hovering over CTA:

Circle changes to:

**OPEN →**

Keep the animation smooth.

---

# 21. SCROLL ANIMATIONS

Use premium, subtle animations throughout.

### Text

Fade + upward movement.

### Images

Mask reveal from bottom to top.

### Large headings

Slow horizontal movement.

### Collection images

Subtle scale from 1.05 → 1.

### Decorative lines

Animate from 0 width → full width.

### Numbers

Count upward when entering viewport.

### Sections

Use staggered animations.

Do NOT animate every single element.

The website should feel expensive, not overloaded.

---

# 22. PAGE TRANSITIONS

When navigating between pages:

Use a short editorial transition.

Example:

Current page fades to black.

Collection title appears briefly.

New page image reveals vertically.

Keep transition around 500–800ms.

---

# 23. MOBILE DESIGN

The mobile version must feel intentionally designed.

Do not simply stack desktop sections.

On mobile:

* Full-screen hero

* Large typography

* Horizontal collection scrolling

* Swipeable editorial galleries

* Sticky minimal navigation

* Touch-friendly buttons

* Reduced animation complexity

Maintain the luxury editorial feeling.

---

# 24. IMPORTANT — AVOID THESE

Do NOT make the website:

* Corporate

* Generic

* Beige-heavy

* Olive-heavy

* Template-like

* Overly rounded

* Full of cards

* Full of gradients

* Excessively animated

* Similar to a SaaS website

* Similar to an online clothing store

Avoid excessive icons.

Avoid excessive borders.

Avoid generic UI components.

---

# 25. FINAL CREATIVE DIRECTION

The final website should feel like:

**A DIGITAL FASHION EDITORIAL.**

The visitor should feel as though they are moving through the designer's world.

Prioritize:

**70% visual storytelling

20% typography

10% UI**

Photography should dominate.

Use generous negative space.

Use asymmetrical layouts.

Use oversized typography.

Use cinematic transitions.

Use subtle parallax.

Use editorial cropping.

Use unexpected image positioning.

Make every section feel intentionally art-directed.

The attached reference is only a structural reference. **Create a completely new visual identity with a black + ivory + burgundy luxury palette and a much more editorial fashion aesthetic.**
